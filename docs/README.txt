SSH Button Next — макет сайта v2 (для согласования)

Откройте index.html в браузере после распаковки ZIP.
Сайт работает локально, без сервера и внешних CDN.
В галерее — 11 согласованных пользователем изображений в исходном качестве:
01-04,06-07,10-11 — исходные файлы; 05, 08, 09 — утверждённые замены.
Скриншоты не изменены: идентичны файлам из комплекта, включая принятые редакции 5, 8 и 9.

Нажатие по изображению раскрывает его в полноразмерном просмотрщике.
Переключатель «Все / Светлая / Тёмная» фильтрует скриншоты без изменения файлов.
Ссылка «Скачать последнюю версию» ведёт на GitHub Releases/latest (страница релиза, а не прямое скачивание APK).

Ничего в GitHub не опубликовано, GitHub Pages не включён.
В структуре assets/icon.png — иконка из предыдущего макета; assets/screens/ — 11 снимков.
